# What's New in 1.22.9

Usage for every mounted disk, a new GPU governor screen, a permanent CPU core unlock that works on Bazzite and SteamOS, and fan control v2 everywhere.

## 1. CPU core unlock: Persistence

- Persistence works on **Bazzite** (SELinux) and **SteamOS** (`nosmt`). On SteamOS the option can be selected again.
- The card now tells two cases apart:
  - **Update available**: the boot service is from an older version of the tool. **Update persistence** installs the current version.
  - **Needs repair**: the boot service did not run when the system started. **Repair persistence** installs it again.
- If the persistence tool is missing, for example after reinstalling the app, the button downloads it first instead of staying greyed out.
- Uses `core_unlock_bc250` 0.2.0.
- Tested on **Bazzite, SteamOS and Arch Linux**. It has not been tested on CachyOS yet, but it is not turned off there either: if you use it on CachyOS, please report any problem.

## 2. GPU governor

- Redesigned screen with the same layout at every window size: Operating profile, Frequency range, Cyan kernel compatibility, Governor service and Voltage laboratory, then the Danger zone.
- Each profile card shows the voltage range Cyan really uses, for example **715 – 905 mV**. The values come from your `config.toml`, so changes made in the Voltage laboratory show up here, +2000 MHz points included.
- The live telemetry tiles were removed from this screen. The Dashboard and Performance already show them.
- Fixed: on SteamOS, the kernel's frequency-ceiling message no longer overflows the frequency range header.

## 3. Fans and interface

- Fan control v2 in the web interface (phone and PC), the TUI and the Decky plugin.
- Better contrast in the dark themes on the CPU / SMU and GPU governor screens.
- Fixed: the CPU screen's selectors no longer look dimmed when they are enabled.
- Remote access starts again by itself after a known failure.

## 4. Monitoring

### 4.1 Disk usage for every disk (suggestion R-5c848eb0)

- Disk usage now covers every real mounted disk, not just `/`. USB and eSATA drives are included.
- Each disk has its own row on the Dashboard, in Performance and in the Sensors list, on desktop, web and TUI.
- A drive appears on the next refresh after you connect it and disappears when you unmount it.
- System mounts that are not real disks are left out, such as the read-only images on Bazzite and SteamOS and duplicate mounts of the same drive.
