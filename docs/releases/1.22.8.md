# What's New in 1.22.8

HelixSR and update window fixes, and new terminal themes.

### HelixSR

- Fixed HelixSR 3.3.0 showing **Repair required** right after installing it, and again after every repair. The author re-published 3.3.0 with a different DLL; 1.22.7 installed it correctly but still compared it with the old one. If HelixSR shows **Repair required**, update to 1.22.8: it shows as installed again, with nothing to reinstall.

### Updates

- Fixed `'NoneType' object has no attribute 'channel'` in the update window when it was opened right after the application started.

### Terminal themes

- The terminal themes were redone so each one looks clearly different: three dark (Clay Dark, Midnight, Graphite), three light (Clay Light, Paper and the new Rose) and three distinctive (the new Lagoon, Phosphor and Dusk). Settings shows them grouped by kind. A theme you had already picked keeps working.

### Maintenance

- Code cleanup so the automatic checks pass again.
