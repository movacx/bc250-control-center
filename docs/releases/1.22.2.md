# What's New in 1.22.2

Changes since 1.22.0.

### SteamOS

- Fixed **Prepare SteamOS compatibility** failing on SteamOS 3.9.5 while building the kernel module, with `GLIBC_2.44 not found`. The build now uses the tools of the installed SteamOS branch, in a separate cache, and system libraries are not replaced.
- Fixed the wrong message for that failure: it said the interface and the protected helper were different versions, which pointed to a reinstall that could not help. Build problems now have their own codes, `BC250-BUILD-001` and `BC250-BUILD-002`.
- New **BC-250 GE-Proton** card in Additional settings › Compatibility › Kernel and graphics, also available in the TUI: install, update, check and remove.
- GE-Proton uses keyboardspecialist's installer, which verifies the download. It requires the FSR4 RADV runtime to be active; restart Steam and select it per game. Do not use FSR4 injection in anti-cheat games.

### Remote Access

- Scan the QR or type the access key to get permanent hardware control. There is no session limit and no separate approval step.
- The QR now carries a one-time code that renews by itself, instead of the access key.
- The active key is shown next to the status, with Copy and New access key.
- Redesigned page: status, pairing and paired devices, with one Download certificate button. Warnings appear only when something needs attention.
- Removed the privacy lock screen and the expiry per device.
- The web server now restarts by itself after an update. Before, it kept running the old version until stopped by hand.
- Fixed a "new device paired" notice that appeared for saved devices every time the page opened.
- Keep the access key private: anyone on your network who has it gets hardware control. **New access key** signs out every device.

### GPU Governor (Cyan)

- Fixed Prepare dependencies stopping on a repeated `fix-freq` line in `config.toml`, which also kept Cyan from starting.
- Fixed Prepare dependencies when Cyan is running without its D-Bus service.

### Installation and Compatibility

- Bazzite 45: async compute can be checked and removed. Installing it stays unavailable until the upstream release supports Bazzite 45.
- Bazzite: removing Cyan now works on images that include it; it is disabled, since it cannot be uninstalled from the image.
- Bazzite: the memory setup resizes its own swapfile instead of stopping, and a full disk is reported as a storage problem.
- Bazzite: updates and connectivity support wait for automatic system updates instead of failing.
- Arch: boot options no longer assume GRUB when another boot loader is in use.
- Arch and CachyOS: a failed AUR download now stops there instead of running the build in the wrong folder.

### Diagnostics and Reports

- Arch and CachyOS: an out-of-date package list is now reported as such, with the fix, instead of blaming the external repository.
- Password timeouts, a locked package manager and other tool errors are now recognized in any system language.
- New diagnosis for Wine failing to start.
- Reports now say whether the amdgpu module exists and whether something blocks it.
- Fixed reports rewriting BC250 codes on accounts with that name, and the doubled Mesa version on Bazzite.

### Updating

- Arch and CachyOS: if the update fails with 404 errors from your mirrors, run `sudo pacman -Syu` and update again.

## Packages

- Arch Linux / CachyOS / Artix OpenRC / SteamOS: `.pkg.tar.zst`
- Fedora / Nobara / Bazzite: `.rpm`
- Ubuntu / Linux Mint / Debian: `.deb`
- Source code and TUI installer: `.tar.gz`

Thanks to everyone who submitted reports and tested the development builds.
