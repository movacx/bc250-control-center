# What's New in 1.22.7

HelixSR, Cyan and pacman fixes.

### HelixSR

- Fixed HelixSR 3.3.0 not installing with `HelixSR-3.3.0.zip as published now is not the archive Control Center checked`. The author uploaded the file again under the same version. Now, when the download does not match the reviewed file, Control Center checks it against the SHA-256 GitHub lists for it at that moment and installs it when it matches.
- Fixed **Build Vulkan kernels** failing with `unknown option: --vulkan` on older HelixSR 3 releases such as 3.1.0. The button now shows only when the installed HelixSR supports it. On older versions, use **Build network files**.

### GPU governor (Cyan)

- Fixed the voltage curve being refused with `The governor TOML does not contain every required packaged safe-point` when the Cyan configuration was written by hand or from another guide and stopped below 2000 MHz. The missing points are now added with Cyan's own values (the ones above 2000 MHz stay commented, as Cyan ships them) and your own points are kept.

### Installation

- Arch / CachyOS: when an action fails with `unable to lock database` and no package manager is running, the terminal now says the lock was left by an interrupted update and gives the command to remove it: `sudo rm /var/lib/pacman/db.lck`. Before, it only said to wait, which never helped.

## Packages

- Arch Linux / CachyOS / Artix OpenRC / SteamOS: `.pkg.tar.zst`
- Fedora / Nobara / Bazzite: `.rpm`
- Ubuntu / Linux Mint / Debian: `.deb`
- Source code and TUI installer: `.tar.gz`

Thanks to everyone who submitted reports and tested the development builds.
