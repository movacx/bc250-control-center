# What's New in 1.22.3

Changes since 1.22.2. Fixes for the failures reported on Bazzite 45.

### Bazzite 45

- Preparing dependencies and fan PWM now wait for the automatic update check that Bazzite runs in the background, instead of stopping with `Transaction in progress`.
- If a download fails with a 404 because the cached repository metadata is out of date, the app refreshes it once and tries again. By hand: `sudo rpm-ostree refresh-md --force`.
- Updating the app when you have layered a package that Fedora 45 no longer ships (for example `coolercontrol`) now says which package blocks the update and how to remove it with `rpm-ostree uninstall`.
- Async compute can now be installed on Bazzite 45. The release was reviewed on Bazzite 44; on 45 its libraries resolve and it still installs as an optional per-game driver. If you test it, `bc250-async-compute status` and `bc250-async-compute test` tell you whether it works on your system.
- Fixed the async compute install reporting an error when the driver had already been enabled for the whole system by an earlier install.
- The memory setup now points to where the result is shown: Additional settings › Memory and swap › View detailed status.

### Remote Access

- **Repair local address** works on Fedora, Bazzite and other systems where `/etc/nsswitch.conf` is managed by authselect. Before, it stopped with `Refusing symbolic link: /etc/nsswitch.conf`.
- The file is never rewritten in that case. If mDNS is already enabled in authselect, the app only checks and publishes the local name. If it is not, the message gives the command: `sudo authselect enable-feature with-mdns4`.

## Packages

- Arch Linux / CachyOS / Artix OpenRC / SteamOS: `.pkg.tar.zst`
- Fedora / Nobara / Bazzite: `.rpm`
- Ubuntu / Linux Mint / Debian: `.deb`
- Source code and TUI installer: `.tar.gz`
